FsDiff: F# automatic differentiation for scientific computing
------------------------------------------------

FsDiff is an automatic differentiation library for the FsSci ecosystem.

FsDiff provides forward- and reverse-mode automatic differentiation for scientific computing, ecological modelling, optimisation, and numerical methods.

## Origins

FsDiff incorporates and extends code from the legacy (and no longer developed) DiffSharp 0.8, keeping the original design based on scalars, vectors, and matrices. For DiffSharp 1.0, the project evolved into a tensor-based architecture for machine-learning workflows. FsDiff instead utilises the original design to focus on scientific computing, for example numerical modelling and optimisation.

DiffSharp was originally developed by Atilim Gunes Baydin and Barak A. Pearlmutter within the Brain and Computation Lab, National University of Ireland Maynooth. The project was later extended through contributions from Don Syme and others.

Original project: https://github.com/DiffSharp/DiffSharp
